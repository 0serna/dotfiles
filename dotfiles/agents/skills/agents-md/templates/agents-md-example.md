## Repository Structure

```text
.
├── src/                  # source code
│   ├── components/
│   └── utils/
├── tests/                # test suite
├── scripts/              # local automation
└── docs/                 # project documentation
```

## Repository Commands

- `npm test`: run tests.
- `npm run lint`: lint the repository.
- `npm run typecheck`: typecheck the repository.
- `npm run format`: format repository files.
